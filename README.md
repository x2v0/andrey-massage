# Сайт массажиста Андрея 💆‍♂️

Легкий, быстрый и полностью независимый статический сайт-визитка для мастера классического массажа. 

Проект создан с нуля с упором на максимальную производительность, современный медицинский дизайн и полную независимость от сторонних платформ.

## 🚀 Ключевые особенности и улучшения
Раньше сайт был сгенерирован в конструкторе Gamma на базе тяжелого React.js и весил **22 МБ**. Мы полностью переписали проект:
* **Нативный код:** 100% чистый HTML, CSS и Vanilla JS. Никаких фреймворков, библиотек и скрытых скриптов слежки.
* **Экстремальная оптимизация:** Вес сайта уменьшен с 22 МБ до **менее 1 МБ** (все изображения переведены в современный формат `.webp` и сжаты).
* **Премиальный дизайн:** Светлая медицинская тема с изумрудными акцентами, белыми карточками и мягкими тенями.
* **Адаптивность:** Идеально выглядит как на смартфонах (как нативное приложение), так и на широких экранах десктопов.
* **Микро-анимации:** Плавное появление блоков при прокрутке (реализовано через `IntersectionObserver`).
* **Независимость (Zero Dependencies):** Сайт статический. Его можно запустить где угодно (на любом хостинге, локально или на флешке) без баз данных и установки софта.
