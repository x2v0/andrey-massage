Инструкция: Как добавить новую статью в блог

Опубликовано: 6 ноября 2026

Добавлять статьи в наш блог очень просто, для этого не нужно быть программистом. Весь процесс занимает 5 минут.

Шаг 1. Создайте файл

Зайдите в папку blog в вашем репозитории на GitHub. Найдите любую существующую статью (например, post-1.html), нажмите на нее, затем нажмите кнопку «Скачать» (или скопируйте весь код).

Шаг 2. Переименуйте

Назовите файл понятным именем на английском, без пробелов. Например: post-backpain.html.

Шаг 3. Отредактируйте текст

Откройте этот файл в любом блокноте на телефоне или компьютере. Найдите:

  • Заголовок <h1>...</h1> — замените текст внутри на название вашей статьи.
  • Дату <div class="date">...</div> — впишите сегодняшнюю дату.
  • Абзацы <p>...</p> — здесь пишется сам текст. Если хотите сделать подзаголовок, используйте <h2>...</h2>.

Шаг 4. Загрузите обратно

Сохраните файл и загрузите его обратно в папку blog на GitHub (кнопка «Add file» -> «Upload files»).

Шаг 5. Добавьте карточку в список

Откройте файл blog/index.html. Найдите любой блок <div class="post-card"> ... </div>. Скопируйте его целиком и вставьте ниже (или выше), чтобы создать новую карточку.

  • В post-date впишите дату.
  • В post-title — название.
  • В post-excerpt — короткое описание.
  • В ссылке <a href="./post-backpain.html"> обязательно поменяйте имя файла на то, которое вы создали в Шаге 2.
Готово! Через 1-2 минуты статья появится на сайте.
